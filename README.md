# NeuralDataAnalysisTools2026

A sandbox and toolkit repository for practicing and benchmarking the analysis of openly accessible multimodal neural data (EEG, fMRI) using Pythonic scientific workflows.

---

## Overview

This repository documents hands-on implementations of computational neuroscience methods, ranging from standard preprocessing pipelines to advanced predictive modeling and cognitive decision-making models.

### Key Goals & Roadmap
- **EEG Preprocessing & Analysis:** Artifact cleaning, ERP analysis, spectral power estimation, time-frequency decomposition, and ERP analysis.
- **fMRI Workflows (Planned):** Voxel-wise timeseries extraction, functional connectivity, and spatial standardisation.
- **Encoding & Decoding Models:** Machine learning models (e.g., MVPA, ridge regression) applied to neural timeseries to predict stimuli/cognitive states.
- **Cognitive Modeling:** Fitting Drift Diffusion Models to joint behavioral (reaction time, choice) and neurophysiological data.
